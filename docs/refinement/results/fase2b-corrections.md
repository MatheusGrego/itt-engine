## Leitura (escrita à mão; as tabelas acima são geradas)

FWER no S0, antes (mid-p puro) → depois (q̂ global + φ̂ por faixa), R = 100:

| Condição | M5 silêncio | M6 burst | Correção que resolveu |
|---|---|---|---|
| base | 0.03 → 0.03 | 0.05 → 0.05 | nenhuma necessária |
| Dispersion k = 10 | 0.54 → 0.09 | 0.52 → 0.13 | φ̂ por faixa (a mediana única dá só 0.18 e 0.18) |
| Dispersion k = 3 | 1.00 → 0.01 | 0.99 → **0.29** | φ̂ por faixa, só no silêncio |
| Dispersion k = 1 | 1.00 → 0.04 | 1.00 → **0.77** | φ̂ por faixa, só no silêncio |
| Trend +0.05 / +0.15 | 0.00 → 0.03 / 0.00 | 1.00 → 0.05 / 0.00 | q̂ global |
| extra: Trend −0.05 / −0.15 | 1.00 → 0.01 / 0.00 | 0.00 → 0.02 / 0.00 | q̂ global |
| extra: Seasonality P = 5 | 0.97 → 0.02 | 0.00 → 0.03 | q̂ global |
| extra: Drift σ = 0.05 | 0.14 → 0.15 | 0.14 → 0.09 | **nenhuma** |
| extra: Drift σ = 0.15 | 0.75 → **0.99** | 1.00 → **0.90** | **nenhuma** (o q̂ piora o silêncio) |

- **q̂ global é necessário e suficiente para tendência e sazonalidade globais.** Ele também devolve o ranking: a AUC do S2 com Trend −0.15 sobe de 0.80 para 1.00. Custo nulo sob o nulo puro.
- **φ̂:**
  - **A mediana única é insuficiente:** o φ real é 1 + λ/k e cresce com a taxa, então uma mediana sub-corrige as arestas de taxa alta.
  - **Por faixa, conserta o silêncio.** O burst continua quebrado com k ≤ 3: a cauda direita do gamma-Poisson é mais pesada que a normal reescalada, e dividir por √φ não mexe no formato da cauda. **O M6 não é confiável com sobredispersão forte.**
- **Drift heterogêneo por aresta não tem conserto com essas ferramentas.** O φ̂ vem da variância dentro das janelas antes e não vê uma mudança de nível que acontece depois. O q̂ global corrige a média, e o drift lognormal sobe a média, o que desloca todo mundo para o silêncio. É a quebra mais séria para dado real (atividade de atores muda sozinha).
- **Custo em poder das correções:**
  - k = 1: poder S2 0.28, S3 0.45.
  - Trend −0.15: S2 0.16, porque a tendência dentro das janelas antes infla o φ̂.
  - O ranking (AUC) fica ≥ 0.97 em todas as condições.
- **Configuração corrigida** usada nas Tarefas 5 e 6: `CorrectedZConfig()` = mid-p + q̂ global + φ̂ por faixa. **O default do M5/M6 não mudou**, porque as correções são opções. Ver Q7.
